# Body map artwork

HealthLit bundles two gender-neutral human silhouette assets used by the interactive body map:

- `body-front.svg` / `body-front.png`
- `body-back.svg` / `body-back.png`

Source: Wikimedia Commons, **Human silhouette gender neutral front** and **Human silhouette gender neutral back**, created by Sebastian Wallroth on July 8, 2026.

License: **CC0 1.0 Universal / public domain dedication**. The PNG files are local renderings of the corresponding SVG source files and are bundled so the body map works without a network connection.

The SVG source files are retained alongside the PNG renderings for provenance and future visual updates.
